# SIN

A single-file cinematic media discovery app.

## Deploy

1. Upload `index.html` to the root of the GitHub repository.
2. Connect the repository to Vercel (or another static hosting provider).
3. Deploy with the default static settings; no build command is required.

The app uses TMDB for metadata. Add your TMDB Read Access Token in Settings. Video playback accepts user-provided authorized direct or embed sources; it does not include movie or TV files.
